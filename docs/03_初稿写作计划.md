# 03 初稿写作计划

## 初稿目标

初稿要形成一篇结构完整、逻辑清晰、能够提交给指导教师审阅的论文。初稿不要求语言完全精炼，但必须保证每一章都有实质内容，尤其是第三章和第四章不能空泛。

## 写作重点

### 第一章 绪论

写清楚研究背景、研究意义、研究现状、研究方法和创新点。

### 第二章 相关概念与理论基础

重点解释新式茶饮、盈利模式、连锁加盟、供应链管理等概念。

### 第三章 蜜雪冰城盈利模式现状分析

这是论文核心章节，应重点写：

1. 企业概况。
2. 收入来源。
3. 成本控制。
4. 加盟扩张。
5. 供应链管理。
6. 品牌营销。
7. 盈利模式总结。

### 第四章 优势与问题分析

优势包括低价定位、规模化扩张、供应链能力和品牌 IP。问题包括加盟管理压力、食品安全风险、利润空间有限、行业竞争激烈和品牌升级困难。

### 第五章 优化建议

建议要对应第四章的问题，避免泛泛而谈。

### 第六章 结论

总结全文观点，说明研究不足。

## 初稿检查清单

- [ ] 论文题目与目录一致。
- [ ] 每章标题层级清楚。
- [ ] 第三章案例分析足够具体。
- [ ] 第四章问题分析有针对性。
- [ ] 第五章建议能对应问题。
- [ ] 参考文献格式统一。
- [ ] 全文没有明显口语化表达。
- [ ] 图表编号和标题完整。

## 初稿写作顺序建议

建议不要从摘要开始写。更稳妥的顺序是：第三章案例分析 → 第四章问题分析 → 第五章优化建议 → 第二章理论基础 → 第一章绪论 → 第六章结论 → 摘要。这样能避免绪论写得很大、后文接不住。
